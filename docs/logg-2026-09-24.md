```
Item ── OnDelete(Guid) ──► Items ── OnDelete ──► │   child → parent

Item  ◄── Todo ─── Items
```

## Fusklapp

```
Home   äger:     todos (List)
       metoder:  AddTodo(string), DeleteTodo(Guid)
       skickar:  <Input OnAdd="AddTodo" />
                 <Items Todos="todos" OnDelete="DeleteTodo" />

Items  tar emot: [Parameter] Todos      (plural = lista)
                 [Parameter] OnDelete   (skickas bara vidare)
       skickar:  <Item Todo="t" OnDelete="OnDelete" />

Item   tar emot: [Parameter] Todo       (singular = ett)
                 [Parameter] OnDelete
       anropar:  OnDelete.InvokeAsync(Todo.Id)

Input  tar emot: [Parameter] OnAdd
       anropar:  OnAdd.InvokeAsync(newText)
```

**Kontrollregler:**
- `[Parameter]` deklareras hos **mottagaren**, aldrig hos den som skickar.
- I en tagg: **vänster** = parameternamn i komponenten du anropar,
  **höger** = något som finns i filen du står i.
- Ett `[Parameter]` gäller **bara propertyn direkt under**. Varje parameter
  behöver sitt eget.
- Den som **äger** datan ändrar den (`Home` lägger till och tar bort).

## Fallgropar jag gick i idag

- `@{ }` i stället för `@code { }`: `@{ }` körs vid varje rendering, så
  listan skulle återställas. Fält hör hemma i `@code`.
- Object initializer utan egenskapsnamn (`new TodoItem{4, "..."}`), rätt är
  `new TodoItem { Id = ..., Text = "..." }`.
- `Id = 4`: `Id` är `Guid`, använd `Guid.NewGuid()` (inte `new Guid()`,
  som ger nollor).
- `[ ]` runt varje item i stället för runt hela listan.
- `@t` skriver ut `TodoWarmup.Models.TodoItem`, rätt är `@t.Text`.
  Uttryck med operatorer kräver `@( ... )`.
- `[Parameter]` lagt i `Home` (skickaren) i stället för `Item` (mottagaren).
- `Todo`/`Todos` förväxlade: fel parameternamn bygger ofta utan fel men
  kraschar i webbläsaren (kolla F12 → Console).
- `OnDelete` kopplat på `Input` i stället för `Items`.
- `todos.Remove(id)`: `Remove` vill ha objektet, rätt är
  `todos.RemoveAll(t => t.Id == id)`.
- Enter lade inte till: lösning är `<form @onsubmit="Add">` +
  `<button type="submit">`.
